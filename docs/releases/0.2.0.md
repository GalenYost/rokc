# Arqis 0.2.0 — Executable Compiler

Status: Planned

This release follows the completed and tested 0.1.0 front end.

## Goal

Produce working native executables from Arqis programs and extend compilation from one source file
to projects with modules, imports, and configured source roots.

## Intended scope

- stable internal representation
- lowering and code generation, initially through an LLVM-oriented backend
- executable output for supported targets
- multiple source files and directory-based projects
- module/import resolution, visibility checking, and project entry points
- cyclic-import diagnostics
- end-to-end compile-and-run tests

The exact IR invariants, supported targets, backend details, and project configuration format will
be specified after 0.1.0 is complete.

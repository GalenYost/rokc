# Arqis 0.1.0 — Core Language

Status: Planned

## Goal

Deliver a small, usable C-like language with a complete front end and executable output.

## In scope

- lexer and token model
- complete AST model
- parser and syntax diagnostics
- semantic analysis and type checking
- declarations and expressions
- control flow
- structs, enums, and type aliases
- basic modules/imports
- pointers and raw-array syntax
- manual memory operations
- `defer`
- a working compiler backend
- executable programs
- parser, type-checker, and end-to-end tests

## Explicitly out of scope

- decorators
- custom `comptime` execution
- generics
- Arqis build scripts
- string interpolation
- struct templates
- advanced standard-library containers
- LLVM-specific IR work
- optimization beyond what is required for correctness

## Acceptance criteria

The release is complete only when valid programs can be lexed, parsed, type-checked, compiled, and executed, and invalid programs produce useful diagnostics.

Every grammar rule in the v0.1 language specification must have parser coverage.

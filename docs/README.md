# Arqis Documentation

This directory is being separated into current language/compiler documentation and release notes.

## Current documentation

- [`language/`](language/): implemented language rules and syntax.
- [`compiler/`](compiler/): implemented compiler architecture.
- [`releases/`](releases/): scope and acceptance criteria for each release.

The existing Markdown files in this directory are retained during the migration. They may still contain planned or speculative material until their content is moved into the appropriate section.

## Planned documentation

Unscheduled or experimental ideas belong in [`../plans/`](../plans/), not in current language documentation.
